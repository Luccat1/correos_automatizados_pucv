Pre-flight validation block to insert before the `processFn` definition:
```javascript
// Pre-flight: validate all recipient email addresses before sending anything (ROBUST-02)
const invalidRows = [];
for (let i = 0; i < rows.length; i++) {
  const rowIndex = i + 2;
  const currentStatus = String(rows[i][statusCol - 1] || '').toLowerCase();
  // Skip rows that are already processed or intentionally skipped
  if (currentStatus.includes('enviado') || currentStatus.includes('borrador') || currentStatus.includes('saltado')) {
    continue;
  }
  // Use template.getRecipientEmail if available (avoids Drive side effects during validation)
  if (typeof template.getRecipientEmail === 'function') {
    const email = template.getRecipientEmail(rows[i], headers, rowIndex, extraData);
    if (email && !isValidEmail(email)) {
      invalidRows.push({ row: rowIndex, email: email });
    }
  }
}
if (invalidRows.length > 0) {
  const detail = invalidRows.map(function(r) { return 'Fila ' + r.row + ': ' + r.email; }).join('\n');
  showAlert('Correos Invalidos', 'Se encontraron correos con formato invalido. Corrijalos antes de enviar:\n\n' + detail);
  return;
}
```

Use `function` expressions in the `.map()` call (not arrow functions) — GAS supports arrow functions in V8 runtime, but use the style already present in the file for consistency. The rest of Main.gs uses arrow functions so arrow functions are fine here.

Do NOT define `getRecipientEmail` on any template in this plan — that is Plan 02's responsibility. The `typeof template.getRecipientEmail === 'function'` guard ensures pre-flight gracefully skips templates that don't yet implement it.
