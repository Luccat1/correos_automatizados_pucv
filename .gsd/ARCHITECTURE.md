## Overview

Collection of **independent Google Apps Script (GAS)** modules for the **Centro de Idiomas PUCV** and related academic units. Each module reads student data from a Google Sheet, generates styled HTML emails, and sends/drafts them via Gmail. There is no shared runtime — each script is copy-pasted into its own GAS project.

## Data Flow

1. **Read** — Open Google Sheet by ID → read headers → map column indexes dynamically.
2. **Filter** — Skip rows already marked as sent/error in the status column.
3. **Process** — For each pending row: extract fields, apply business logic (discounts, CCs, Drive sharing), build HTML + plain-text email.
4. **Send** — Call `GmailApp.sendEmail()` or `GmailApp.createDraft()`.
5. **Update** — Write status + timestamp back to the sheet (batch or per-row).

## Conventions

**Naming:**
- Config objects: `CFG_<SUFFIX>` or `CONFIG`
- Column maps: `COL_<SUFFIX>` or `HEADERS_<SUFFIX>` or `EXPECTED_HEADERS_<SUFFIX>`
- Private helpers: `functionName_Suffix_()` (trailing underscore = GAS private convention)
- Public entry points: descriptive Spanish names (`enviarCertificados`, `sendConfirmationEmails`)

**Structure:**
Each script follows the same layout:
1. Configuration constants
2. Column mapping
3. Public functions (main + test)
4. Business logic helpers
5. Sheet helpers
6. HTML/text template builders

**Testing:**
- Every script has a dedicated test function that sends to `luciano.cataldo@pucv.cl` or `Session.getActiveUser()`.
- Some scripts support `createDrafts` mode for safe preview.
- No unit tests exist.
